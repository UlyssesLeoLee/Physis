# 回顾模板（Retrospective / KPT Template）

> **用途**：项目 / Phase / Hypercare 结束后的团队回顾，使用 KPT 格式。
> **对应工作流步骤**：
> - 148 振り返り（Retrospective）→ `28_workflow.md` §11.52
> - 116 問題管理（Problem）→ §11.29（事故复盘的事后回顾可用本格式简化）
> **关联**：`36_project_plan.md`（Phase 边界）；`43_hypercare_plan_template.md`（Hypercare 收尾）；`40_postmortem_template.md`（单次事故的复盘）；`27_qa_register.md`（行动项转化）。
