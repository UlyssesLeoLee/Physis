## 2. 文档目的

本文档记录 GVPE 在 v0.6 / v0.7 / v0.8 三个迭代周期内，**对 `gvpe-math` / `gvpe-core` / `gvpe-memory` 三个基础 crate 公开 API 表层的累计增量**。

填补现有文档矩阵的关键缺口：
- 现有 `docs/02_modules/` 11 份 spec 全部为 2026-08-20 编写，**无任何一份覆盖 v0.6 之后代码**（实证见 §3）。
- `22_vector_detailed_design.md` 是 `gvpe-vector`（语义检索）模块的详细设计，**与 `gvpe-math`（基础数学库）无关**——名字相近易混淆。
- v0.6 / v0.7 / v0.8 三个 commit 的 API 增量信息仅存在于 commit message 与代码 `/// doc`，**无独立 spec 文档**。

本文档是补这块缺口的第一刀（最小而完整），不重写 11 份既有 spec，只汇总三 crate 的 v0.6+ 公开 API。
